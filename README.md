## About This Repository

Welcome to my Penetration Testing portfolio.

This repository documents my practical learning journey in penetration testing, ethical hacking, network reconnaissance, vulnerability assessment, and security testing.

The purpose of this project is to develop practical cybersecurity skills, understand common security vulnerabilities, explore attack methodologies, and learn how to identify and recommend appropriate security controls.

All testing activities are conducted in authorised lab environments or on systems for which permission has been granted.

## Objectives

* Understand penetration testing methodologies.
* Develop network reconnaissance skills.
* Identify potential security vulnerabilities.
* Perform network scanning and enumeration.
* Understand common web application vulnerabilities.
* Practise vulnerability assessment.
* Document security findings and recommendations.
* Improve Linux command-line and cybersecurity skills.

## Practical Learning Areas

### 1. Information Gathering

Learning how to collect information about authorised testing targets.

### 2. Network Scanning

Using Nmap to identify open ports, running services, and potential network security weaknesses.

### 3. Enumeration

Investigating discovered services to understand their configurations and potential vulnerabilities.

### 4. Vulnerability Assessment

Identifying security weaknesses and understanding their potential impact.

### 5. Web Application Testing

Exploring common web application security vulnerabilities using authorised testing environments.

### 6. Exploitation

Understanding how vulnerabilities can be exploited in controlled laboratory environments.

### 7. Reporting

Documenting findings, assessing risks, and recommending appropriate security improvements.

## Learning Approach
